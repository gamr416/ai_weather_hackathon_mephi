## Главная идея в одном абзаце

**Perceiver-VAE** — универсальный «кодек» для погодных полей: сжимает разные метеопеременные в общее скрытое (latent) пространство и умеет их обратно восстанавливать. Дальше это latent-пространство можно использовать для сжатия данных и для прогноза погоды без работы напрямую с огромными физическими картами.
