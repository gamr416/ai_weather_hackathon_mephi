# Погодные параметры

Погодные данные делят на **три типа**. Подробные коды — в [ECMWF parameter DB](https://codes.ecmwf.int/grib/param-db/).

---

## 1. Наземные (surface) — 2D

Поля около поверхности Земли. Часто нужны в прикладных задачах.

### Основные

| Код | Простыми словами | Ед. |
|-----|------------------|-----|
| **T2M** (`2t`, `t2m`) | Температура воздуха на высоте 2 м | K |
| **MSLP** (`msl`, `mslp`) | Давление, приведённое к уровню моря | Pa |
| **U10 / V10** (`10u`/`10v`, `u10`/`v10`) | Ветер на 10 м (восток / север) | m/s |
| **TP** | Осадки за N часов (часто 1/6/12/24 ч) | м (накопленные) |
| **TP6H** | Осадки именно за **6 часов** (в задании: `tp6h`) | м |

### Реже (но входят в задание хакатона)

| Код | Простыми словами |
|-----|------------------|
| **SST** | Температура поверхности моря |
| **TCC** (`tcc`) | Общая облачность (доля 0–1) |
| **TCWV** (`tcwv`) | Total column water vapour — столбец водяного пара |
| **TCW / TCWP** | Общий столб воды (жидкость+пар+лёд); часто рядом с TCWV, но **не то же самое** |
| **D2M** | Точка росы на 2 м |
| **SP** | Давление на поверхности (не MSL) |
| **SF** | Выпавший снег |
| **RO** | Сток воды |
| **U100 / V100** | Ветер на 100 м |

### Набор хакатона (28 каналов)

**Всегда вместе** (не surface-only трек). Полное ТЗ: [task.md](task.md).

**Surface (8):** `t2m, mslp, u10, v10, tp6h, sst, tcwv, tcc`  
**Pressure (20):** `T, U, V, Z, Q` × уровни `{1000, 925, 850, 700}` hPa

Алиасы: `2t`/`t2m`, `msl`/`mslp`, `10u`/`u10`, `10v`/`v10`.  
SST — только по океанской маске. Статика (`lsm`, orography, sin/cos φ) — conditioning, не в CR.

### Радиация

| Код | Простыми словами |
|-----|------------------|
| **SSRD** | Коротковолновая радиация вниз на поверхность (солнце) |
| **STRD** | Длинноволновая радиация вниз на поверхность (тепло) |
| **SLHF** | Скрытый тепловой поток с поверхности |
| **TISR** | Солнечная радиация на верхней границе атмосферы |
| **TTR** | Длинноволновой поток на верхней границе атмосферы |

### Почва

| Код | Простыми словами |
|-----|------------------|
| **EVAP / E** | Испарение за N часов |
| **SWVL1–4** | Влажность почвы по слоям |
| **STL1–4** | Температура почвы по слоям |

## 2. Атмосферные — 3D

Поля по **вертикали**. Высоту обычно задают не метрами, а **уровнями давления** (гПа / hPa).

Типичные **13 уровней** в DL-погоде (от земли вверх):

```
1000 → 925 → 850 → 700 → 600 → 500 → 400 → 300 → 250 → 200 → 150 → 100 → 50 гПа
```

| Код | Простыми словами | Ед. |
|-----|------------------|-----|
| **T** | Температура | K |
| **Z** | Геопотенциал (связано с «высотой» изобары) | m²/s² |
| **Q** | Удельная влажность | kg/kg |
| **R** | Относительная влажность | % |
| **U / V** | Горизонтальный ветер | m/s |
| **W** | Вертикальная скорость | Pa/s (часто) |

В **хакатоне** фиксированы ровно **4 уровня**: `1000, 925, 850, 700` hPa  
и переменные `T, U, V, Z, Q` → **20** atmospheric-каналов (+ 8 surface = **28**). См. [набор выше](#набор-хакатона-28-каналов).

## 3. Статические (топография) — 2D, почти не меняются

Не нужно пересчитывать каждый шаг времени — это «карта местности».

| Код | Простыми словами |
|-----|------------------|
| **lat / lon** | Координатная сетка |
| **lsm** | Маска суша/море |
| **slt** | Тип почвы |
| **orography / gh / z** | Высота рельефа |
| **sdor, slor, isor, anor** | Статистики субсеточного рельефа (неровность, наклон, анизотропия, угол) |

### Время как признак

| Код | Простыми словами |
|-----|------------------|
| **hod** | Час суток (часто `h/24`) |
| **doy** | День года (часто `d/366`) |

---

## Классический «учебный» набор

**Атмосфера:** `[Z, T, Q, U, V]` × 13 уровней = **65** каналов  
**Поверхность:** `[T2M, MSLP, U10, V10, TP]` = **5**  
**Итого ≈ 70** погодных параметров.

**Статика (часто):** `[gh, lsm, slt]`.

У Aurora чуть иначе: без TP в базовом наборе → **69** каналов + 3 статики (см. [03_aurora.md](03_aurora.md)).
