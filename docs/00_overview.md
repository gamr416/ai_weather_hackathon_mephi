# Обзор проекта

## Что это

Хакатон МИФИ по **сжатию погодных данных**: автокодировщики над полями **ERA5** при **ограниченной** обучающей выборке.

Идейный контекст (Perceiver / Aurora / CRA5) — вспомогательный. Официальная постановка — в [task.md](task.md).

## Зачем

Большие реанализы и foundation-модели требуют терабайты и кластеры. Вопрос хакатона обратный:

> Какой **минимальный** набор глобальных 6h состояний достаточен, чтобы на **одной GPU** выучить полезное 28-канальное представление нижней атмосферы?

Представление должно:

- компактно кодировать поля (**×32–×64** по bitstream);
- хорошо восстанавливать surface и pressure;
- переноситься на простой **+6h latent-прогноз** при замороженном encoder;
- воспроизводиться при фиксированном data/compute-бюджете.

## Две задачи

| # | Суть |
|---|------|
| **1. Кодек** | AE + quantized bottleneck, exact roundtrip, CR ×32/×64 |
| **2. Probe** | Замороженный encode/decode + маленькая latent-модель на +6h |

## Baseline

**VAEformer / CRA5** — ориентир качества (не цель по экстремальному CR). Формальные пороги non-inferiority — §6 в [task.md](task.md).

## Железо

Лимит ТЗ: ≤24 GB VRAM, ≤20M params.  
Локально: **RTX 3060 12 GB** — влезает в лимит; полный Aurora — нет. См. [03_aurora.md](03_aurora.md).
