# Обзор проекта

## Что это

**Perceiver-VAE** — идея взять архитектуру **Perceiver IO** (уже использована в foundation-модели погоды **Aurora**) и сделать из неё **VAE-кодек**: универсальный энкодер/декодер погодных полей в одно latent-пространство.

## Зачем

1. **Сжатие** — хранить погоду компактнее (в духе CRA5 / VAEformer для ERA5).
2. **Прогноз в latent** — обучать прогнозные модели не на сырых картах, а на сжатых представлениях.
3. **Универсальность** — один кодек под разные переменные, сетки и уровни; дообучение на новых типах полей.

## Откуда ноги растут

| Работа | Роль для нас |
|--------|----------------|
| [Perceiver IO](https://arxiv.org/abs/2107.14795) | Архитектура: произвольный вход → фиксированный latent → произвольный выход через query |
| [Aurora](https://arxiv.org/abs/2405.13063) | Perceiver encoder/decoder для погоды; гибкость по переменным и разрешению |
| [CRA5 / VAEformer](https://arxiv.org/abs/2405.03376) | Пример extreme compression ERA5 через VAE-трансформер |
