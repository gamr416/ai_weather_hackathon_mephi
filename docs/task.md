## 1. Цель и мотивация

Исследовать, можно ли **на одной GPU** и **небольшом наборе** глобальных метеокадров обучить компактное представление **полного состояния нижней атмосферы** (28 каналов).

Представление должно:

1. давать **сжатие ×32–×64** (фактический bitstream);
2. **качественно восстанавливать** поля (non-inferiority к VAEformer — см. §6);
3. сохранять информацию, полезную для **простого прогноза в latent** (замороженный энкодер);
4. позволять измерить **минимальный объём уникальных обучающих данных**, при котором критерии выполняются.

> Реконструкция — не самоцель. Нужно компактное, переносимое, воспроизводимое представление при фиксированном data/compute-бюджете.

Ориентир по кодекам: **VAEformer → CRA5** [arXiv:2405.03376](https://arxiv.org/abs/2405.03376). Экстремальная компрессия CRA5 (~300×) **не требуется** — исследуем умеренные ×32–×64 при малом объёме данных.

## 2. Единая конфигурация данных

**Нет отдельных surface- и upper-air-треков.** Одна модель, один 28-канальный тензор, сетки **0.5°** и **0.25°**, шаг **6 часов**, глобально.

### 2.1. Приземные поля — 8 каналов

| Код | WeatherBench 2 | Смысл | Ед. |
|-----|----------------|-------|-----|
| `t2m` | `2m_temperature` | Температура на 2 м | K |
| `mslp` | `mean_sea_level_pressure` | Давление к уровню моря | Pa |
| `u10` | `10m_u_component_of_wind` | Зональный ветер 10 м | m/s |
| `v10` | `10m_v_component_of_wind` | Меридиональный ветер 10 м | m/s |
| `tp6h` | `total_precipitation_6hr` | Осадки за предыдущие 6 ч | m |
| `sst` | `sea_surface_temperature` | Температура поверхности моря | K |
| `tcwv` | `total_column_water_vapour` | Столбец водяного пара | kg/m² |
| `tcc` | `total_cloud_cover` | Облачность | 0–1 |

**Правила оценки surface:**

- `u10`, `v10` — **отдельно**; \(\sqrt{u_{10}^2+v_{10}^2}\) — диагностическая метрика.
- `mslp`: физический RMSE дополнительно в **hPa**.
- `tp6h`: дополнительно в **mm/6h**.
- `sst`: восстанавливается и считается **только по океанской маске**; над сушей после нормализации = 0.

### 2.2. Атмосферные поля — 20 каналов

Ровно **4 уровня**: \(P = \{1000, 925, 850, 700\}\) hPa.

| Код | WeatherBench 2 | Смысл | Ед. | Каналов |
|-----|----------------|-------|-----|---------|
| `T` | `temperature` | Температура | K | 4 |
| `U` | `u_component_of_wind` | Зональный ветер | m/s | 4 |
| `V` | `v_component_of_wind` | Меридиональный ветер | m/s | 4 |
| `Z` | `geopotential` | Геопотенциал (в отчёте также \(Z/g\)) | m²/s² | 4 |
| `Q` | `specific_humidity` | Удельная влажность | kg/kg | 4 |

### 2.3. Порядок каналов (фиксирован)

```
[t2m, mslp, u10, v10, tp6h, sst, tcwv, tcc,
 T1000, T925, T850, T700,
 U1000, U925, U850, U700,
 V1000, V925, V850, V700,
 Z1000, Z925, Z850, Z700,
 Q1000, Q925, Q850, Q700]
```

**Статика** (`land_sea_mask`, орография, `sin φ`, `cos φ`) — только **conditioning** encoder/decoder.  
Не восстанавливаются и **не входят** в числитель compression ratio.

### 2.4. Источник данных

**Предпочтительно:** WeatherBench 2 ERA5 Zarr (0.25°, 6h, есть `total_precipitation_6hr`):

```
gs://weatherbench2/datasets/era5/
1959-2023_01_10-wb13-6h-1440x721_with_derived_variables.zarr
```

Доступ анонимный (`xarray` + `zarr` + `dask` + `gcsfs`).  
Выбрать переменные, `sel(level=[1000,925,850,700])`, ограничить время.

| Сетка | Как получить |
|-------|----------------|
| **0.25°** | Из Zarr напрямую: **721 × 1440** (с полюсами) |
| **0.5°** | Один раз first-order conservative remapping → **360 × 720** (lat −89.75…89.75, lon 0…359.5); единые веса + локальный Zarr |

**Альтернатива:** CDS ERA5 single-levels + pressure-levels (00/06/12/18 UTC).  
`tp6h` из сырого `tp` считать аккуратно — поэтому WB2 предпочтительнее.

## 4. Задачи

### Задача 1 — компактное восстановление (кодек)

Автоэнкодер с **квантованным bottleneck**. Официальный compression ratio по **сериализованному bitstream**:

\[
\mathrm{CR} = \frac{32\, T\, C\, H\, W}{8\, B}
\]

где \(B\) — полный размер bitstream в байтах (латенты + side information + заголовки), \(C=28\), float32 в числителе.

Обязательно: **exact equality** квантованных символов после encode→decode.  
Без entropy coding результат = **latent reduction**, в codec-зачёт **не** идёт.

### Задача 2 — проверка представления (latent probe)

1. Заморозить encoder и decoder.
2. Обучить маленькую latent-модель (**≤ 2 M** params) предсказывать latent через **+6 h**, затем decode в поля.
3. Probe: ровно **1024** обучающие пары, ≤ **5000** шагов.

Проверяет, что bottleneck несёт динамику, а не только копирует вход.  
Опционально: masked-reconstruction probe (в духе W-MAE).

## 5. Метрики

### Latitude-weighted RMSE / NRMSE

RMSE считается **в физических единицах** отдельно по каждому погодному полю \(f\):

\[
\mathrm{RMSE}_f = \sqrt{
  \frac{\sum_{t,i,j} \cos\varphi_i\,(\hat x - x)^2}
       {\sum_{t,i,j} \cos\varphi_i}
},\qquad
\mathrm{NRMSE}_f = \frac{\mathrm{RMSE}_f}{\sigma_{f}}
\]

**Знаменатель \(\sigma_f\)** (уточнение организаторов): из репозитория
[LadCast](https://github.com/tonyzyl/ladcast) (`static/ERA5_normal_1979_2017.json`)
или климатологии CDS. В проекте: `data/ref_stats/sigma_official_28ch.npz`
(LadCast для пересекающихся каналов; `tcc`/`tcwv` — lat-weighted std по локальному train-пулу).
Сборка: `python scripts/metrics/build_official_sigma.py`.

Train-нормализация (`norm_stats.npz`) используется только для обучения; **скоры** \(S_\ast\) —
только по official NRMSE.

| Score | Определение |
|-------|-------------|
| \(S_\mathrm{surface}\) | Равновзвешенное среднее NRMSE по **8** surface |
| \(S_\mathrm{pressure}\) | Равновзвешенное среднее NRMSE по **20** (переменная×уровень) |
| \(S_\mathrm{all}\) | \(\frac12 S_\mathrm{surface} + \frac12 S_\mathrm{pressure}\) |

Дополнительно: физический RMSE, PSNR (диапазон 0.5–99.5 перцентиля), сферические спектры, метрики экстремальных осадков.

### Non-inferiority к VAEformer

Для каждого тестового времени:

\[
\Delta = 100\left(\frac{\mathrm{NRMSE}_\mathrm{model}}{\mathrm{NRMSE}_\mathrm{reference}} - 1\right)
\]

95% CI — парный **block bootstrap** (блоки 7 дней, 2000 повторов).

Для latent-прогноза: относительное улучшение NRMSE vs **persistence** и vs тот же probe на признаках референса.

## 6. Критерии допуска (non-inferiority)

| Критерий | при **32×** | при **64×** |
|----------|-------------|-------------|
| Верхняя граница 95% CI для общего NRMSE (\(S_\mathrm{all}\)) | ≤ **+3%** | ≤ **+7%** |
| Верхняя граница 95% CI для surface / pressure score | ≤ **+5%** | ≤ **+8%** |
| Верхняя граница для отдельного критического поля | ≤ **+7%** | ≤ **+10%** |
| Нижняя граница разности PSNR | ≥ **−0.25 dB** | ≥ **−0.5 dB** |
| Ухудшение spectral error | ≤ **5%** | ≤ **10%** |
| Фактический CR + exact roundtrip | **обязательны** | **обязательны** |
