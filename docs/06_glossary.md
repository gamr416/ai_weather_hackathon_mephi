# Глоссарий

Короткие определения без воды.

| Термин | Простыми словами |
|--------|------------------|
| **Реанализ** | «Лучшая реконструкция прошлого»: модель + все наблюдения. Пример: ERA5 |
| **NWP** | Numerical Weather Prediction — классический численный прогноз (IFS, GFS) |
| **Foundation model** | Большая предобученная модель, которую дообучают под задачи (Aurora) |
| **Latent** | Сжатое скрытое представление данных внутри нейросети |
| **VAE** | Вариационный автоэнкодер: учит вероятностный код + восстановление |
| **Кодек** | Пара encode/decode: сжал ↔ разжал |
| **Rate–distortion** | Баланс: размер/стоимость кода vs ошибка восстановления |
| **Perceiver / Perceiver IO** | Transformer с маленьким latent-бутылочным горлышком и query-выходом |
| **Cross-attention** | Один набор токенов «спрашивает» другой (queries смотрят на keys/values) |
| **Query-driven decoding** | Выход задаётся запросами (какая переменная, уровень, сетка) |
| **Swin Transformer** | Vision Transformer с окнами; в Aurora — 3D backbone |
| **LoRA** | Дешёвое дообучение: маленькие адаптеры вместо полной перестройки весов |
| **Авторегрессия** | Прогноз следующего шага подаётся снова на вход для более дальнего горизонта |
| **Pressure level** | Вертикальный уровень по давлению (850 гПа ≈ ~1.5 км и т.п.) |
| **гПа / hPa** | Гектопаскаль; 1000 гПа ≈ у поверхности |
| **Геопотенциал Z** | Связан с высотой поверхности постоянного давления |
| **Surface / single level** | 2D поле у поверхности (T2M, MSLP…) |
| **Static fields** | Почти неизменные поля (рельеф, суша/море) |
| **Patch** | Кусок карты, который сеть видит как один токен |
| **Downscaling** | Переход с грубой сетки на мелкую |
| **Swath** | Полоса покрытия спутника (не полная глобальная сетка) |
| **CDS** | Climate Data Store — склад датасетов Copernicus |
| **ERA5** | Глобальный реанализ ECMWF, 0.25°, почасовой |
| **CRA5** | Сильно сжатый ERA5 нейрокодеком |
| **WeatherBench2** | Бенчмарк и облачные данные/метрики для DL-погоды |
| **RMSE / ACC / CRPS** | Стандартные метрики ошибки / аномалий / вероятностного качества |
| **IFS HRES** | Оперативный высокоточный прогноз ECMWF |
| **GFS** | Глобальная прогноз-модель NOAA |
| **MAE / L1** | Средняя абсолютная ошибка; часто base loss в Aurora |
