# Aurora — foundation-модель Earth System

Статья: [arXiv:2405.13063](https://arxiv.org/pdf/2405.13063) · код: [microsoft/aurora](https://github.com/microsoft/aurora)

## Простыми словами

**Aurora** — большая модель Microsoft для прогноза атмосферы (и вариантов: воздух, волны). Она:

1. **кодирует** разнородные поля в единый 3D latent;
2. **прогоняет время** через 3D Swin Transformer UNet;
3. **декодирует** обратно в физические переменные.

Именно **Perceiver** в encoder/decoder делает модель гибкой к разным переменным, разрешениям и числу уровней давления.

---

## Какие переменные

### Базовая погода

`[Z, T, Q, U, V]` × 13 уровней + surface `[T2M, U10, V10, MSLP]` + static `[lsm, slt, z]`  
→ **69** каналов + **3** статики.

### Air Pollution

+ атмосферные `[CO, NO, NO2, SO2, GO3]` и набор surface/химических полей.

### Wave

+ гидрологические (высота/период/направление волн и т.п.) + доп. статика.

## Архитектура (схема пайплайна)

```
Вход: карты на (T−1, T)
        ↓
3D Perceiver Encoder  — переменные + уровни давления → эмбеддинги
        ↓
Latent Atmospheric Input  (3D тензор)
        ↓
3D Swin Transformer UNet  — пространственно-временной анализ
  (+ LoRA при дообучении на длинный горизонт)
        ↓
Latent Atmospheric Output
        ↓
3D Perceiver Decoder  — queries (в т.ч. по уровням давления) → физ. поля
        ↓
Выход: прогноз на (T+1)
```

### Детали, которые важны для Perceiver-VAE

- Вход: два снимка `[t−6h, t]`.
- Patch → MLP по переменным → **cross-attention** Perceiver → фиксированный latent.
- Эмбеддинги: **positional, scale, level, time** — поэтому работают разные сетки и число уровней.
- Новая переменная ≈ новый MLP в encoder/decoder, без полного переобучения с нуля.
- Backbone: 48 блоков Swin 3D (Encoder `[6,10,8]`, Decoder `[8,10,6]`).
- LoRA на Attention/MLP при rollout fine-tuning.

---

## Обучение и инференс

- Авторегрессия: прогноз скармливается обратно как вход.
- Loss: взвешенный L1 (MAE) с физически осмысленными весами.
- Инференс: нужно явно передать масштаб, набор переменных, число уровней.

---

## Почему это важно для нашего проекта

Perceiver-VAE по сути говорит: **возьмём Perceiver-подход из Aurora и сделаем из него полноценный VAE-кодек** (сжатие + универсальное latent), а не только encoder/decoder внутри forecast-модели.

---

## Есть ли отдельный «Aurora autoencoder»?

**Коротко: нет готового AE-кодека.**

- У Aurora есть **3D Perceiver encoder** и **decoder**, но они часть **прогнозного** стека: encode → Swin (эволюция во времени) → decode.
- Это **не** VAE со целью rate–distortion / сжатия вроде CRA5.
- Отдельного пакета/чекпоинта «только codec» Microsoft не выкладывает.
- Теоретически можно прогнать encode→decode, минуя backbone, но веса **не обучены** на реконструкцию как кодек — для хакатонной задачи сжатия это слабый старт.

Идеи архитектуры (Perceiver, гибкие переменные/уровни) — да; готовые веса «как VAEformer» — нет.

## Железо: RTX 3060 12 GB — что реально

Источники цифр: [официальный usage](https://microsoft.github.io/aurora/usage.html) (~**40 GB** VRAM на обычный 0.25°), README (~**500 MB** скачивание для Small), HF LFS (Small ckpt **~451 MB**, full pretrained **~5 GB**), статья (модели **~113M / 660M / 1.3B**; 0.1° — около лимита **A100 80 GB** на один шаг).

| Действие | Вердикт на 3060 12 GB |
|----------|------------------------|
| `pip install microsoft-aurora` | **Да** (wheel ~225 KB; лёгкие зависимости поверх уже стоящего torch) |
| Импорт / API / toy batch | **Да** |
| Inference **AuroraSmallPretrained** (debug, ~113M) | **Частично да** — на toy/маленькой сетке точно; глобальный 0.25° (721×1440) может упереться в 12 GB — проверять с `torch.cuda` / кропом |
| Inference полный **0.25°** (~1.3B, официально ~40 GB) | **Нет** |
| **Aurora 1.5** (~32 GB по докам) | **Нет** |
| **0.1° HighRes** (~80 GB класс) | **Нет** |
| Fine-tune / train полного Aurora | **Нет** (даже инференс не влезает; обучение — десятки GPU A100 в статье) |
| Использовать как готовый AE под ×32–×64 | **Нет** (см. выше) |

**Практичный вывод для хакатона:** пакет можно поставить и «потрогать» Small на синтетике; для ТЗ — **свой AE ≤20M** на **28 каналах** (8 surface + 4 уровня), CR ×32/×64 по bitstream, sweep по \(N\), baseline VAEformer. Полный Aurora не нужен.
