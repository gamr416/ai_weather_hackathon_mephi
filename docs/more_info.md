Инструменты для работы с погодными данными
Погодные данные в сути своей устроены как изображения (classic CV), но при этом снабжены определенной структурой:
• системы координат (геометрия "изображений");
• различные физические каналы (в отличие от 3-4 каналов в картинках);
• единицы измерений и трехмерные структуры (с учетом высот);

Эти особенности данных мотивируют к использованию более сложных систем хранения (сжатия) "погодных снимков" + алгоритмам доступа и описания метаданных (систем координат и единиц измерения), а также отдельных пакетов визуализации. В этом посте изложены самые полезные библиотеки для работы с погодой.

Xarray (https://docs.xarray.dev/en/stable/)
Python библиотека, которая в сути своей дополняет numpy (https://numpy.org/) со стороны описания каналов и систем координат, а также интерфейсов для доступа к данным различных форматов (NetCDF5 (https://en.wikipedia.org/wiki/NetCDF), GRIB (https://ru.wikipedia.org/wiki/GRIB), Zarr (https://en.wikipedia.org/wiki/Zarr_(data_format)), GeoTIFF (https://ru.wikipedia.org/wiki/GeoTIFF), etc.). Главным преимуществом библиотеки является интерфейс доступа и работы с данными — он идентичен numpy (и pandas в какой-то степени).

Данная библиотека позволяет работать с физическими данными, снабжая многоранговые тензоры данных дополнительными индексами, именуемыми "координатами", которые могут иметь свои физ. размерности. По этим "координатам" можно производить поиск, выделение или изменение параметров основного тензора. Помимо систем координат к каждому рангу или каналу (размерности) тензора можно представить JSON описания с названиями физ. полей, их единиц измерения и т.п..

Полный функционал xarray при работе со спутниковыми растерами раскрывается с доп. модулями, обеспечивающими работу с проекциями — Coordinate Reference System (CRS) (https://corteva.github.io/rioxarray/latest/getting_started/crs_management.html). Туда же относится pyproj (https://pyproj4.github.io/pyproj/stable/) библиотека для работы с проекциями.

GDAL (https://gdal.org/en/stable/)
Сишная библиотека, представленная как API к Python (osgeo (https://gdal.org/en/stable/api/python/index.html) библиотека) и C++ для работы с погодными данными без лишних абстракций. У данной библиотеки также имеется набор скриптов (https://gdal.org/en/stable/programs/index.html), обеспечивающих быстрое решение тех или иных задач при работе с проекциями и конвертациями погодных данных. Она является стандартом в работе со спутниковой информацией и используется в огромном количестве пайплайнов обработки метеоданных ввиду её скорости.

Эта "тяжелая артилерия" не раз пригодилась при работе с большими растерами GOES17/18 за счет GDAL Warp и Grid API.

Cartopy (https://scitools.org.uk/cartopy/docs/latest/)
Отличная надстройка над matplotlib (https://matplotlib.org/) для работы с визуализацией карт. Тут всё просто — указываем нужную проекцию или сетку данных и можем спокойно отрисовывать поверх погодных полей географию материков, стран и т.п., а также можем отображать имеющиеся сетки в разные проекции.

Must have для аналитиков геоданных!

Shapely (https://shapely.readthedocs.io/en/2.1.1/manual.html)
Библиотека для пространственного анализа. В основном используется геоаналитиками. Она позволяет строить абстракции над геометрическими объектами в различных географических проекциях — точки, линии, полигоны (мультиполигоны). Эта библиотека интегрирована с различными форматами хранения данных (WKT (https://ru.wikipedia.org/wiki/WKT), GeoJSON (https://ru.wikipedia.org/wiki/GeoJSON), GeoTIFF, etc.) и при этом позволяет работать с большим спектром метрических функций (поиск расстояний, углов, площадей и т.п.).

К этому классу библиотек идет и GeoPandas (https://geopandas.org/en/stable/), но Shapely куда полезнее (IMHO). Ещё она бывает полезна при работе с координатами станционных/радарных данных на погодных сетках.

Metpy (https://unidata.github.io/MetPy/latest/index.html) и pvlib (https://pvlib-python.readthedocs.io/en/stable/)
Python библиотеки для расчета метеорологических параметров аналитическим/численным путем. 

Metpy полезна для:
• термодинамических расчетов (распределения температуры, точки росы, etc.);
• динамики атмосферы (вертикальный сдвиг ветра, дивергенции, вихри, etc.);
• анализа устойчивости атмосферы (CAPE индексы, анализ влажности и осадков);
Эта библиотека помогает при работе с готовыми погодными полями от моделей прогноза погоды и используется в основном метеорологами (+ через неё можно рисовать всякие профили и диаграммы).

Pvlib сфокусирована вокруг моделирования солнечной геометрии и радиационных полей. Через неё удобно считать Clear-Sky модели радиации и моделировать коэф. прозрачности атмосферы за счет доп. погодных параметров.
